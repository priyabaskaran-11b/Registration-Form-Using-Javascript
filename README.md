# Registration Form Validation Project

This project is a simple and responsive Registration Form created using HTML, CSS, and JavaScript. The form performs real-time validation for user inputs and provides instant feedback to improve user experience.

## Features

* Real-time form validation
* Name field validation
* Email format validation
* Password strength checker
* Show/Hide password functionality
* Disabled submit button until all inputs are valid
* Success message after successful registration
* Responsive modern UI design
* Glassmorphism effect with animations

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Validation Rules

* Name field should not be empty
* Email should contain a valid email format
* Password should contain:

  * Minimum 6 characters
  * At least one number
  * At least one special character
